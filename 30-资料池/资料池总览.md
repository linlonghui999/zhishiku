# 资料池总览

> 资料池只负责保存和等待处理，不是日常阅读入口。日常入口回到 [[00-开始这里/知识库首页]]。

## 一句话理解

资料池像仓库：东西可以多，但入口必须少。

资料进入知识库后，只需要问：

1. 属于哪个主题？沉香 / 修行 / 自媒体 / 项目
2. 有没有价值？保留 / 归档 / 删除候选
3. 能不能提炼？观点 / 选题 / 话术 / 项目动作

## 每天只处理 1 条

固定动作：

```text
资料 → 判断价值 → 补属性 → 提炼观点 → 回链主题 → 形成输出
```

## 不要做什么

- 不要在资料池里深度整理所有资料。
- 不要为了分类而分类。
- 不要把资料池当首页。
- 不要轻易删除原始资料。
