# flomo 同步入口

> flomo 是灵感入口，Obsidian 是判断、连接、提炼和输出系统。

## 当前定位

flomo 里的内容不要直接当成成熟知识。

每条 flomo 进入 Obsidian 后，只做四步：

```text
灵感 → 判断价值 → 归类 → 提炼成观点/话术/选题
```

## 当前导入位置

- flomo 原始卡片：[[01-收件箱/flomo]]
- 收件箱总说明：[[01-收件箱/收件箱说明]]
- 每日处理入口：[[20-每日产出/今日升级]]

## 每天只处理 1 条 flomo

处理模板：

1. 这条灵感在说什么？
2. 它属于：沉香 / 修行 / 自媒体 / 项目 / 用户偏好？
3. 它能变成什么：观点 / 金句 / 直播话术 / 短视频选题 / 项目动作？
4. 处理完放哪里？

## 分流建议

- 沉香、线香、原料 → [[10-主题/沉香]] 或 [[项目管理/沉香抖音卖货/项目总览]]
- 修行、成长、美好生活 → [[10-主题/修行]]
- 自媒体、AI、直播、短视频 → [[10-主题/自媒体]] 或项目区
- 用户表达偏好 → [[项目管理/沉香抖音卖货/用户画像与对话学习/AI对话学习与用户偏好规则]]
- 暂时没有输出价值 → 保留在 flomo 原始区，不急着处理

## 使用原则

- 不一次性清空所有 flomo。
- 不把 flomo 当最终知识库。
- 不直接复制成主题页。
- 有价值的才提炼。
- 能服务项目的优先处理。
