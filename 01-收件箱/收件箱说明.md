# 收件箱说明

> 收件箱只做一件事：临时接收新资料。它不是长期仓库，也不是日常阅读入口。

## 一句话理解

所有新东西先丢进来，但每天只处理 1 条。

```text
新资料 → 收件箱 → 判断价值 → 分流到主题/资料池/项目/删除候选
```

## 什么可以进收件箱

- flomo 灵感
- 网页文章
- 抖音收藏/喜欢内容
- 临时想法
- 用户和 AI 的关键对话
- 外语资料
- 未分类资料

## 每条资料只问 5 个问题

1. 它解决什么问题？
2. 属于哪里：沉香 / 修行 / 自媒体 / 项目 / 全局？
3. 有没有价值：保留 / 提炼 / 归档 / 删除候选？
4. 能不能变成一个观点、选题、话术或项目动作？
5. 最后应该放到哪里？

## 分流规则

- 原始资料 → [[30-资料池/资料池总览]]
- 沉香观点 → [[10-主题/沉香]]
- 修行观点 → [[10-主题/修行]]
- 自媒体观点 → [[10-主题/自媒体]]
- 项目相关 → [[项目管理/项目管理总览]]
- 每日观点 → [[20-每日产出/今日升级]]
- 对话偏好 → 对应项目的用户画像与对话学习区

## 不要做什么

- 不要在收件箱深度整理。
- 不要一次清空所有资料。
- 不要让收件箱变成第二个资料库。
- 不要把未经判断的资料直接放进主题页。

## 每天最低动作

每天只处理 1 条：

```text
打开一条 → 判断价值 → 提炼一句话 → 分流
```
