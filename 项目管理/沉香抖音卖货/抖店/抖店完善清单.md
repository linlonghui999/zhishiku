# 抖店完善清单

> 短视频负责引流和打标签，抖店负责承接信任和成交。

## 商品结构

### 入门产品

- 试香装
- 低门槛线香
- 适合第一次购买

### 主推产品

- 高品质野生沉香线香
- 明确原料背书
- 明确适用场景

### 背书产品

- 野生沉香原材料展示
- 不一定主推成交，用于提升信任

## 商品页必须讲清

- 原料是什么
- 适合什么场景
- 味道是什么感觉
- 和普通线香差别在哪里
- 新手怎么选
- 不适合谁

## 商品标题方向

- 睡前静心沉香线香
- 茶室书房沉香线香
- 野生沉香原料线香
- 新手入门沉香线香试香装

## 商品详情页检查

- [ ] 标题是否包含“沉香线香”
- [ ] 是否讲清使用场景
- [ ] 是否展示原料
- [ ] 是否有新手说明
- [ ] 是否有风险/适用边界
- [ ] 是否和短视频话术一致

## 短视频挂车规则

每条视频只挂一个最匹配商品：

- 睡前内容 → 睡前静心线香
- 新手避坑 → 试香装/入门线香
- 原料内容 → 高品质线香或原料展示
- 茶室空间 → 茶室书房线香
