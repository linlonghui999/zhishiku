# 直播铺垫逻辑

## 直播前短视频要完成的认知

1. 用户知道这是一个高品质沉香线香账号。
2. 用户知道线香和睡前、静心、修行、成长有关。
3. 用户知道线香背后有野生沉香原材料。
4. 用户知道直播间会讲清楚原料、味道、适合谁、不适合谁。

## 直播间核心话术方向

- 第一次买线香，不要先追贵，先找到适合自己的味道。
- 好的线香不是香精冲鼻，而是干净、稳定、有层次。
- 我为什么敢讲线香品质？因为我手里有野生沉香原材料。
- 你买的不是一支香，是一个让自己慢下来的入口。

## 直播间产品顺序

1. 入门线香：低门槛成交
2. 高品质线香：解释原料与味道
3. 野生沉香原料：展示高度与信任
4. 组合/试香装：降低第一次购买风险
