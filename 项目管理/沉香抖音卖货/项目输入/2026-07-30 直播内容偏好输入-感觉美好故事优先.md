# 2026-07-30 直播内容偏好输入-感觉美好故事优先

## 原始输入整理

用户指出：

- 直播不是非要讲干货。
- 沉香知识点如果讲得枯燥，用户不会停留。
- 除非能用很美的语言表达，否则不要硬讲沉香知识。
- 用户看直播，看的是一种感觉、一种美好，或者有用，或者能解决某个问题，或者有故事可以听。
- 本质是：用户觉得有价值才会停留。
- 可以不讲沉香干货，可以聊别的。
- 主框架可以来自：我擅长的、我向往的、我想讲的。
- 沉香可以作为“皮肉”加入进去，而不是每句话都围绕沉香知识。
- 这样既可以吸引人，也可以卖货。
- 以后用户输出的内容都要记录，不管之前还是以后，沉淀进资料库，用来学习用户的表达方式和偏好。

## 偏好提炼

用户更适合的直播内容不是“知识讲解型”，而是：

> 感觉型 / 美好型 / 故事型 / 陪伴型 / 生活主线型直播。

沉香不是唯一主角，而是生活主线里的一个道具、一种气味、一种审美、一种商品承接。

## 对直播策略的修正

旧逻辑：

> 讲沉香知识 → 展示专业 → 建立信任 → 卖货

新逻辑：

> 讲用户愿意听的生活、美好、故事、成长 → 形成感觉和停留 → 用沉香/线香承接场景 → 自然卖货

## 内容判断标准

一段直播内容只要满足以下任意一个，就可以讲：

1. 有感觉：让人觉得舒服、安静、美好。
2. 有用：能解决一个生活小问题。
3. 有故事：让人愿意继续听。
4. 有共鸣：用户觉得“这说的是我”。
5. 有商品承接：能自然带到沉香、线香、原材料。

不满足以上任何一点，就不要讲。
