# 直播话术互联网学习笔记

## 学习结论

直播话术不能只是好听，必须有运营目的。

常见结构：

1. 吸引用户。
2. 留住用户。
3. 推出产品。
4. 解释为什么买。
5. 解释为什么在我这里买。
6. 解释为什么现在买。

另一种更简化的结构：

1. 互动话术：提升停留、评论、关注。
2. 产品话术：讲卖点和价值。
3. 成交话术：促进转化。

## 对本项目的应用

沉香直播不能照搬低价福利型直播。

原因：

- 沉香不是刚需。
- 用户信任成本高。
- 用户不懂，容易听不下去。
- 不能只靠吆喝和逼单。

适合本项目的结构：

> 用户场景/痛点 → 原料或线香区别 → 产品展示 → 美学表达 → 场景选择 → 轻成交

## 本次修正

删除/避免：

- 先停十秒。
- 让房间慢下来。
- 把工作变成娱乐。
- 人少的时候慢慢讲。
- 今天先不着急。
- 空泛“发现美好”口号。

改为：

- 新手买香先问用途。
- 原材料适合学习，线香适合日常。
- 睡前、书房、茶桌三个场景分开讲。
- 美学表达只作为塑品的一部分。
- 互动指令要具体：打“睡前/书房/茶桌/原料”。
