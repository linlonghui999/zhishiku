# 直播内容底层逻辑-用户相关版

> 旧问题：讲沉香、讲美好、讲玄感，容易变成“主播自嗨”，用户听完不知道和自己有什么关系。
>
> 新原则：所有内容都必须从用户正在经历的问题出发，再落到沉香原材料、线香、场景和选择。

## 一、底层逻辑

用户进直播间，不是来听我们抒情的。

用户只关心四件事：

1. 跟我有什么关系？
2. 我能不能听懂？
3. 我会不会少踩坑？
4. 我买了以后到底怎么用？

所以直播内容不是：

> 沉香很美 → 我来描述美

而是：

> 用户有一个具体场景/问题 → 用沉香或线香给一个可感知的解决方式 → 顺便建立专业和产品价值

## 二、把资料拆成原子

### 1. 把工作变成娱乐

不是直播里说“我热爱工作”。

而是让观众看到：

- 主播正在玩香、试香、拆料、布置场景。
- 直播不是硬讲课，是现场做一件有意思的事。
- 用户进来不是听销售，而是看一个人怎么把香玩明白。

### 2. 发现美好，记录美好，分享美好

不要讲成口号。

要落到用户能感受到的细节：

- 桌面干净一点。
- 睡前少刷 10 分钟手机。
- 茶桌旁边多一点香气。
- 买香少踩一个坑。
- 今天知道一块几百块钱沉香是什么样。

### 3. 美好生活

美好生活不是高大上的艺术表达。

对普通用户来说，美好生活是：

- 今天睡得好一点。
- 房间舒服一点。
- 花的钱不冤一点。
- 买东西少被骗一点。
- 有一个小东西让自己心情好一点。

### 4. 诗词和艺术

诗词不是主菜，是调味。

先讲用户关心的，再用一句诗词提升气氛。

顺序是：

> 用户问题 → 产品场景 → 一句美好表达

不能反过来。

## 三、新直播内容公式

### 公式一：用户问题型

用户问题 → 错误做法 → 正确判断 → 展示产品 → 轻引导

例：

很多新手买沉香，第一句就问：沉不沉水？

但对普通人来说，沉不沉水不是第一问题。你真正要问的是：这东西你买回去怎么用？是闻？是摆？是送人？还是学习？

如果只是想日常让房间舒服一点，我建议先从线香开始；如果你想学沉香原料，再看这种小料。

### 公式二：场景型

用户生活场景 → 香能加入的位置 → 产品选择 → 评论互动

例：

如果你家里有书桌、茶桌，或者晚上经常刷手机停不下来，你不一定需要买很贵的沉香原材。

你可能只需要一支味道干净、不刺鼻的线香，让这个空间有一个“该慢下来”的提醒。

想知道书房适合什么香，评论打“书房”。

### 公式三：避坑型

常见误区 → 为什么错 → 怎么判断 → 看手上这块料

例：

新手买沉香不要只听产区名。

同样叫星洲，品质差别很大；同样叫惠安，也不是每一块都适合你。

你先看三件事：味道干不干净、价格和用途匹不匹配、你买回去会不会真的用。

### 公式四：对比型

A 选择 → B 选择 → 适合谁 → 商品承接

例：

原材料和线香不是谁高级谁低级。

原材料适合想学习、收藏、上炉品闻的人；线香适合日常使用，睡前、书房、茶桌都方便。

如果你刚入门，我建议先从线香建立味觉，再慢慢看原料。

## 四、直播间第一优先级：留人钩子

好的钩子必须满足三个条件：

1. 用户听得懂。
2. 跟用户利益有关。
3. 后面能接产品。

### 可以直接用的钩子

- 新手买沉香，第一句别问沉不沉水，先问你买回去干什么。
- 几百块钱的沉香原材料能不能买？能，但你要知道它适合谁。
- 如果你只是想让房间舒服一点，不一定要先买沉香原料。
- 同样叫星洲沉香，为什么有的好闻，有的很冲？
- 惠安系为什么很多人喜欢？因为它对新手更友好，没那么压迫。
- 买香最怕的不是贵，是你买回去根本用不上。
- 第一次买香，别装懂，先从“闻着舒不舒服”开始。
- 沉香原材料不是普通人不能碰，而是要先知道怎么玩。
- 你家里有书房、茶桌、床头，这三种场景选香完全不一样。
- 刚进来的朋友，我现在讲的是：新手怎么少花冤枉钱认识沉香。

## 五、原材料直播讲法

### 不要这样讲

- 不要上来讲玄、缘分、伤口、能量。
- 不要一直说它美，但不告诉用户怎么判断。
- 不要用太多行业词，把用户讲跑。

### 要这样讲

拿起一块原材料，只讲四个普通人能听懂的问题：

1. 这块大概是什么类型？
2. 它适合拿来做什么？
3. 新手看它容易误判在哪里？
4. 如果不买原料，日常使用该怎么选线香？

## 六、30 分钟用户相关版流程

### 0-3 分钟：利益开场

今天不先讲沉香多高级，先讲新手怎么少花冤枉钱。

如果你第一次接触沉香，记住一句话：先问用途，再问价格，最后才问产区。

### 3-8 分钟：展示原料

我手上这块料，先不讲复杂术语。

你看它适合学习、品闻，还是适合做日常使用？这个很关键。

### 8-13 分钟：用户避坑

很多人买沉香，最大问题不是买不起，而是买回去不知道怎么用。

原料、线香、手串、摆件，适合的人完全不一样。

### 13-18 分钟：场景承接

如果你只是想睡前、书房、茶桌用，线香更实用。

如果你想学习沉香味道、产区差异、原料状态，再慢慢看原材料。

### 18-23 分钟：产品塑品

这类原料的价值，是让你看到线香背后的底子。

不是每个人都需要买原材料，但懂一点原材料，你买线香就不会只看包装和名字。

### 23-27 分钟：开价/引导

第一次接触，不建议你硬上高价。

你可以先从小份、试香、入门料开始。预算舒服，买回去会用，这才是对的。

### 27-30 分钟：互动循环

评论区打：原料、线香、书房、睡前、星洲、惠安。

我按你的场景讲怎么选。

## 七、直播间内容判断标准

每句话说出口前，先问：

- 这句话跟用户有什么关系？
- 用户听完能不能少踩坑？
- 用户听完知不知道下一步怎么选？
- 能不能自然接到产品？

如果不能，就删掉。
