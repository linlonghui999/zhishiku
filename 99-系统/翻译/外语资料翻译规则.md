# 外语资料翻译规则

> 默认原则：知识库的日常阅读语言是简体中文。英文、韩文、日文等资料可以保留原文，但不能只留下外语原文。

## 新资料进入时

如果资料不是简体中文，先做四步：

1. 判断语言：英文 / 韩文 / 日文 / 其他。
2. 保留原文，不删除。
3. 添加「简体中文整理」区。
4. 再决定是否提炼为卡片或进入主题页。

## 简体中文整理区格式

```markdown
## 简体中文整理

- 中文标题：
- 原文语言：
- 一句话摘要：
- 这条资料对我有什么用：
- 可提炼观点：
- 适合进入主题：沉香 / 修行 / 自媒体 / 跨领域
```

## 翻译优先级

1. 已经进入主题 MOC 的外语资料
2. 沉香科研/市场资料
3. 自媒体方法论资料
4. 韩文/日文平台案例
5. 只作为背景的低价值资料

## 不做的事

- 不把外语标题直接丢进 MOC，不解释。
- 不为了翻译而翻译，必须同时判断价值。
- 不删除原文，除非已经确认完全重复且有中文版本。
